# NEBULA BOOST — Android First Build

Это исходный проект первой Android-версии NEBULA BOOST на C# / .NET MAUI.

## Что уже есть
- Тёмный графитовый игровой интерфейс с красно-оранжевым акцентом.
- Главный экран.
- Базовая информация об устройстве и версии ОС.
- Память, используемая самим приложением (это не общая RAM телефона).
- Кнопка Smart Check и экран диагностики.
- Раздел-заготовка «Мои игры».
- Переключение RU / EN, полный перевод текстов главного экрана и сохранение выбора после перезапуска.

## Честные ограничения этой ранней версии
- Это исходный проект, не готовый подписанный APK.
- Температура, реальный FPS в сторонних играх, частоты GPU и системное управление производительностью пока не реализованы: универсальный API не предоставляет их одинаково на всех телефонах.
- Кнопка проверки не разгоняет телефон и не разблокирует FPS. Следующий этап — подключить поддерживаемые Android API и проверять функции на реальном устройстве.

## Сборка APK в Windows
1. Установить Visual Studio 2022 с workload **.NET Multi-platform App UI development** и Android SDK.
2. Открыть `NEBULA.BOOST/NEBULA.BOOST.csproj`.
3. Восстановить NuGet-пакеты.
4. Для теста выбрать Android Emulator или подключённый телефон и нажать Run.
5. Для APK в терминале Developer PowerShell:
   ```powershell
   dotnet publish .\NEBULA.BOOST\NEBULA.BOOST.csproj -f net10.0-android -c Release
   ```
   Требуется установленный .NET 10 SDK и MAUI Android workload. Путь результата зависит от установленной версии SDK; ищите APK в `NEBULA.BOOST\bin\Release\net10.0-android\publish\`.

## iPhone
iOS target намеренно не включён в этот Android-first архив. Для iOS потребуется Mac с Xcode, добавление `net10.0-ios`, настройка provisioning/signing и отдельная сборка. Для публикации/установки на обычный iPhone нужны подпись Apple и соответствующий способ распространения.
